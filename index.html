How to use this page for a release — click to expand
  1. Release Queue — shows which houses have a stage (F/L/O/Q) due right now. This is a live mirror of your systems: it never releases anything itself, it only tells you what's ready.
  2. Go release that stage in MarkSystems: House Release grid → find the house → double-click its row to open Create Work Orders → confirm. If MarkSystems shows a Duplicate Contracts Found warning, review it — but note that only catches an exact duplicate contract, not two separate work orders on the same cost code at different amounts, which is what this page's own Duplicate check catches instead (that's the class of duplicate that's actually been slipping through). Pick a Price Option, and MarkSystems generates a preview PDF — one page per work order — for you to look over before it finalizes.
  3. Back here, click Review released WOs on that row to jump straight to the work orders that release produced, checked for duplicates and budget mismatches.
  4. Any cost code tagged Job-Specific depends on lot size / site conditions, not a fixed budget — its OK/Caution/Flagged badge isn't meaningful, so confirm it against the drawings and check the separate "matches drawings/site" box instead. Use the Job-Specific filter to see every one of those 14 codes for every house, including ones with no work order yet.
  5. Use House Lookup any time to see one house's complete picture across every system.

Everything shown is computed live from the source APIs on every refresh. The only things this page ever remembers on its own are optional notes and review checkmarks you add — they never change what stage a house is at or hide anything.

Step 2 above is based on an actual recorded walkthrough of doing a release in MarkSystems. Download the recording if you want to see it yourself — it's a Windows Steps Recorder file (a screenshot + description for each click, not a video) opened by extracting the .zip and opening the .mht file inside. Note: since it's a real recorded session, it shows a specific vendor's contact info and one specific house's address/amounts, not sanitized placeholders.
